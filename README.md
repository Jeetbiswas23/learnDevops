# MERN DevOps Starter

A deliberately simple MERN-style frontend + Express backend starter for learning DevOps.

## Structure
- frontend: React + Vite
- backend: Node.js + Express API
- MongoDB: not required for the starter; a health endpoint is provided so we can add MongoDB later.

## Run locally
### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev

The frontend expects the API at http://localhost:5000.
